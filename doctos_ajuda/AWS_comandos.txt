****************************************************
*** Precisa atualizar a aplicação a partir do git, usando ssh.
****************************************************************

Gerar chave como determina o git
ssh-keygen -t ed25519 -C "ennio.gomide@gmail.com"
dar enter, não precisa  informar nada, inclusive senha.

incluir a chave no agente ssh
eval "$(ssh-agent -s)"

ssh-add ~/.ssh/id_ed25519

cat ~/.ssh/id_ed25519.pub (para leitura da chave publica)

Liberar o acesso no github. cadastrar no settings, no ssh key.


para autenticar no git
ssh -T git@github.com

Aula 99 
***************************************************
***** insalar o banco de dados
*****************************************************
sudo apt install postgresql postgresql-contrib (instalar)

para acessar o comando shell do postgres

sudo -u postgres psql

Para alterar a senha
\password postgres

Para criar o banco de dados
CREATE DATABASE carros;


***************************************************
***** CONFIGURANDO O AMBIENTE  NO SERVIDOR
*****************************************************
Instalar as funcionalidades adicionais do python. o que vem é mais enxuto
sudo apt install build-essential python3

ferramentas adicionais
sudo apt install python3-dev

instalar para permitir a criação do ambinete virtual
sudo apt install python3-venv

Instalar o pip
sudo apt install python3-pip


Criar o ambiente virtual
python3 -m venv venv (carrosv0)

Para ativar a venv
source carrosv0/bin/activate

Instalar as dependências (requirments)

pip install -r requirements.txt

*********************************************************
**** Atualizando a aplicação
*********************************************************

Para instalar algum pacoate.
pip unstall psycopg2
instalando novos pacotes e gerando novo requirmente

pip freeze > requirements.txt

Na maquina local
git commit -am "mensagem" 
git push origin main

no servidor, 
git pull

Para executar o servidor
python3 manage.py runserver 0:porta (8080)
