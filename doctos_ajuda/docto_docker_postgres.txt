Para instalar o postgres no docker sozinho.
docker run --name my-postgres - p 5433:5432 -e POSTGRES_PASSWORD=postgres -d postgres
--name -> nome do container
-p - porta. por padrão roda na 5432, na máquina host, expõe na 5433
-d para não ficar com a tela presa. postgres é o nome da imagem.

se não tiver, instala.
baixa e instala se não tiver.

localhost:5433, acessa o host
